# qFoldIT Runtime Adapter Boundary

This repository is a visualization adapter for the canonical qFoldIT Rust runtime-adapter contract.

Canonical contract: `qfoldit.runtime-adapter/1.0`

Blender remains an asset/visualization runtime. Scientific truth remains in qFoldIT scientific contracts and independent validators.

```text
qfoldit-core
  -> runtime-adapters
  -> Blender visualization adapter
  -> Blender / UEFN
  -> Submission
  -> Validator
  -> Evidence 1.1
```

New cross-runtime semantics belong in `qfoldit/UEFN-QFOLDIT/crates/runtime-adapters`.
